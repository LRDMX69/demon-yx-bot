# Local MoE model artifacts

`demonyx-moe.json` is generated by `yarn train:moe` from `data/moe-training.jsonl`. It is a small keyword-gated mixture-of-experts model designed to route common requests locally without requiring a hosted model or API key. The trainer is deterministic apart from its timestamp and is intentionally transparent so operators can inspect or replace the learned weights.

The committed artifact is regenerated during the local validation flow after corpus updates.

Validation commands: `yarn train:moe`, `yarn evaluate:moe`, `yarn test`, and `yarn test:syntax`.

The artifact contains eight expert gates and 32 labeled training examples. It is intentionally a transparent router rather than a hosted general-purpose language model.
